## Featured projects

### [Observatório BLCS](./projects/digital-humanities/observatorio-blcs)

Interactive dashboard on readers, circulation and demand at the Lúcio Craveiro da Silva Library, 2020–2026. This is my master's project work: auditing and harmonising institutional data, building the dashboard and validating it with library professionals.
HTML · CSS · JavaScript (SVG) · Python · [Open the dashboard ↗](https://joo2002vsc.github.io/Portfolio--Joao_Garcao/projects/digital-humanities/observatorio-blcs/)

### Vitória SC accounts

Two linked projects on the accounts of Vitória Sport Clube, from 2012/13 to 2025/26:

- **[SQL analysis](./projects/data-analysis/contas-vitoria-sql):** a SQLite database built from the club's annual reports, analytical queries, charts and a strategic analysis. Python · SQLite · Matplotlib · automated tests
- **[Dashboard](./projects/web-development/dashboard-contas-vitoria):** the presentation layer of the SQL project, with indicators, ratios and a query explorer. JavaScript · Chart.js · [Open the dashboard ↗](https://joo2002vsc.github.io/Portfolio--Joao_Garcao/projects/web-development/dashboard-contas-vitoria/)

### [Compound Interest Simulator](./projects/data-analysis/simulador-juros-compostos)

A Monte Carlo simulator of a stock and crypto portfolio, with periodic contributions, random inflation and shock scenarios. The Python engine and the JavaScript web version are tested and compared automatically.
Python · NumPy · JavaScript · GitHub Actions · [Open the simulator ↗](https://joo2002vsc.github.io/Portfolio--Joao_Garcao/projects/data-analysis/simulador-juros-compostos/web/)
