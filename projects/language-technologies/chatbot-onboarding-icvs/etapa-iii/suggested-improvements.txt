1. Refine the Ollama Prompt for Consistency
Issue: Evidence sections are misnumbered (e.g., "Section 1" vs. full names) and sometimes contradictory (e.g., providing steps but claiming insufficient info).
Improvement: Update the user_prompt in answer_with_ollama_rag to enforce full section names and stricter rules. Example tweak:

user_prompt = (
    f"Context:\n{context}\n\n"
    f"Question: {question}\n\n"
    "Answer briefly using only the context. If insufficient, say so without listing steps.\n"
    "After the answer, include:\n"
    "Evidence: list of full section names used (e.g., 'Administrative and Technical Units')."
)

Lower temperature to 0.1 for less variability and fewer contradictions.


2. Enhance TF-IDF Baseline Answer
Issue: Just concatenates text without summarization, leading to noisy, irrelevant output (e.g., including "ICVS, who we are").
Improvement: Modify answer_with_tfidf to summarize or filter. Add a simple post-processing step:

def answer_with_tfidf(question, k=TOP_K):
    hits = retrieve_top_k(question, k)
    # Filter low-score hits (e.g., below 0.3) to reduce noise
    filtered_hits = [h for h in hits if h['score'] > 0.3]
    context = "\n\n".join([h['text'] for h in filtered_hits])
    summary = f"Retrieved context (top {len(filtered_hits)} relevant sections):\n{context}"
    return {"method": "tfidf", "question": question, "hits": filtered_hits, "answer": summary}

This keeps it simple but more focused.
