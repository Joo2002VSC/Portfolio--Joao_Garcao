# Memorial de Vários Simplices

## 🇵🇹
Transcrição e codificação XML de um excerto da obra **"Memorial de Vários Simplices"** (Curvo Semmedo, 1700), a partir de facsimilado, seguindo critérios de edição digital de texto. Trabalho em grupo com Joana Azevedo.

O projeto documenta duas fases de trabalho:

- 📄 [`transcricao-diplomatica.pdf`](./transcricao-diplomatica.pdf) — transcrição diplomática de base, preservando a grafia original (incluindo o "s" longo e abreviaturas) e a paginação da obra
- 🏷️ [`memorial-varios-simplices.xml`](./memorial-varios-simplices.xml) — primeira versão da codificação, com marcação estrutural (título, subtítulo, parágrafos, quebras de linha) segundo um esquema XML próprio
- 🏷️ [`memorial-varios-simplices-tei.xml`](./memorial-varios-simplices-tei.xml) — versão final, com codificação semântica detalhada em **TEI Lite** (ingredientes, dosagens, condições, intervenções, precauções, etc.) e modernização ortográfica assinalada através de `<choice>`/`<orig>`/`<reg>`

---

## 🇬🇧
XML transcription and encoding of an excerpt from **"Memorial de Vários Simplices"** (Curvo Semmedo, 1700), from facsimile, following digital text editing criteria. Group work with Joana Azevedo.

The project documents two stages of work:

- 📄 [`transcricao-diplomatica.pdf`](./transcricao-diplomatica.pdf) — base diplomatic transcription, preserving the original spelling (including the long "s" and abbreviations) and the work's pagination
- 🏷️ [`memorial-varios-simplices.xml`](./memorial-varios-simplices.xml) — first version of the encoding, with structural markup (title, subtitle, paragraphs, line breaks) following a custom XML schema
- 🏷️ [`memorial-varios-simplices-tei.xml`](./memorial-varios-simplices-tei.xml) — final version, with detailed semantic encoding in **TEI Lite** (ingredients, dosages, conditions, interventions, precautions, etc.) and spelling modernization marked through `<choice>`/`<orig>`/`<reg>`
