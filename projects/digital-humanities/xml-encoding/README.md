# Codificação XML · XML Encoding

## 🇵🇹

Projeto desenvolvido em conjunto com **Joana Azevedo** no âmbito da cadeira de **Edição e Arquivo Digital** (Mestrado em Humanidades Digitais, Universidade do Minho), sob orientação da Prof. Idalete.

Transcrição de um excerto da obra **"Memorial de Vários Simplices"**, a partir de facsimilado, com codificação e marcação em **XML**, seguindo critérios de edição digital de texto.

- **Ficheiro XML:** [`memorial-varios-simplices.xml`](./memorial-varios-simplices.xml)
