# Análise de Dados · Data Analysis

## 🇵🇹

Projeto desenvolvido em grupo (com **Joana Azevedo**) no âmbito da cadeira de **Análise e Visualização de Dados (AVD)** (Mestrado em Humanidades Digitais, Universidade do Minho).

O projeto combina análise textual e estatística: extração de lemas, colocações e sintagmas nominais, análise de sentimento, e visualização de dados quantitativos em gráficos.

**Tecnologias:** Python (spaCy), análise de sentimento, geração de gráficos

- **Apresentação completa:** [`apresentacao-avd.pptx`](./apresentacao-avd.pptx)

## 🇬🇧

Project developed as a group (with **Joana Azevedo**) for the **Data Analysis and Visualization (AVD)** course (Master's in Digital Humanities, University of Minho).

The project combines textual and statistical analysis: lemma extraction, collocations and noun chunks, sentiment analysis, and quantitative data visualization through charts.

**Technologies:** Python (spaCy), sentiment analysis, chart generation
