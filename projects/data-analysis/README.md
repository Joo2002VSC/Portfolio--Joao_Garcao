# Análise de Dados · Data Analysis

## 🇵🇹
Projetos pessoais de análise de dados em SQL e Python, desenvolvidos de forma autodidata, fora das cadeiras.

- **[`contas-vitoria-sql/`](./contas-vitoria-sql)**: projeto pessoal (autodidata, fora das cadeiras) — base de dados **SQLite** com as contas do Vitória Sport Clube (SAD, Clube e Grupo consolidado, 2012/13–2025/26), 26 consultas SQL (CTEs, funções de janela, vistas), gráficos em Python e uma análise estratégica que cruza as contas com o desempenho desportivo, as regras da UEFA e a centralização dos direitos de TV.
- **[`leituras-sql/`](./leituras-sql)**: projeto pessoal — análise em **SQLite** do meu histórico de leituras (exportação do Goodreads), que também gera a página "Em Números" e a lista de leituras do [blog literário](../web-development/blog-literario): modelo em três tabelas, 13 consultas (CTEs, funções de janela, datas) e gráficos sobre ritmo de leitura, notas, autores e época de publicação.
- **[`simulador-juros-compostos/`](./simulador-juros-compostos)**: projeto pessoal — simulador **Monte Carlo** de juros compostos em **Python/NumPy** para uma carteira de ações e cripto, com aportes semanais, mensais ou anuais, inflação aleatória e fatores exógenos (crises, regulação cripto, choques de inflação, pausas nos aportes). Inclui testes automáticos (GitHub Actions) e uma [versão interativa](https://joo2002vsc.github.io/Portfolio--Joao_Garcao/projects/data-analysis/simulador-juros-compostos/web/) em HTML/CSS/JS.
- **[`diario-linguas/`](./diario-linguas)**: projeto pessoal — base de dados **SQLite** para acompanhar a aprendizagem de neerlandês, francês e italiano (vocabulário, sessões de estudo e revisões), analisada com consultas SQL e gráficos em Python. Os dados incluídos são simulados, para demonstração.

A análise de texto da cadeira de Análise e Visualização de Dados está em [`language-technologies`](../language-technologies); o exercício de OCR em [`digital-humanities/ocr`](../digital-humanities/ocr); o trabalho de Análise de Dados para Negócios em [`business-and-innovation`](../business-and-innovation).

## 🇬🇧
Personal data analysis projects in SQL and Python, self-directed and outside coursework.

- **[`contas-vitoria-sql/`](./contas-vitoria-sql)**: self-directed personal project (not coursework) — a **SQLite** database of Vitória Sport Clube's accounts (SAD, Club and consolidated Group, 2012/13–2025/26), 26 SQL queries (CTEs, window functions, views), Python charts and a strategic analysis linking the accounts to sporting performance, UEFA rules and TV rights centralisation.
- **[`leituras-sql/`](./leituras-sql)**: personal project — a **SQLite** analysis of my reading history (Goodreads export), which also generates the "Em Números" page and the reading list of my [literary blog](../web-development/blog-literario): a three-table model, 13 queries (CTEs, window functions, dates) and charts on reading pace, ratings, authors and publication period.
- **[`simulador-juros-compostos/`](./simulador-juros-compostos)**: personal project — a **Monte Carlo** compound interest simulator in **Python/NumPy** for a stock and crypto portfolio, with weekly, monthly or yearly contributions, random inflation and exogenous shocks (market crashes, crypto regulation, inflation spikes, contribution pauses). Includes automated tests (GitHub Actions) and an [interactive version](https://joo2002vsc.github.io/Portfolio--Joao_Garcao/projects/data-analysis/simulador-juros-compostos/web/) in HTML/CSS/JS.
- **[`diario-linguas/`](./diario-linguas)**: personal project — a **SQLite** database to track my learning of Dutch, French and Italian (vocabulary, study sessions and reviews), analysed with SQL queries and Python charts. The included data are simulated, for demonstration.

Text analysis work from the Data Analysis and Visualisation course is in [`language-technologies`](../language-technologies); the OCR exercise in [`digital-humanities/ocr`](../digital-humanities/ocr); the Business Data Analysis project in [`business-and-innovation`](../business-and-innovation).
