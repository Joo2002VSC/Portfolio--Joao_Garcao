# Projeto Inicial

## 🇵🇹
Primeira fase do trabalho de AVD, individual: exploração de técnicas de processamento de linguagem natural (PLN) e análise de sentimento, aplicadas a dois corpora distintos:

- **Análise de sentimento do conto "Cinderela"** ([`sentimento-cinderela.py`](./sentimento-cinderela.py), [`cinderela.txt`](./cinderela.txt), [`grafico-sentimentos.png`](./grafico-sentimentos.png))
- **Entrevista pessoal** (à avó do autor, Rosa Reis) — transcrição ([`entrevista-definitiva.md`](./entrevista-definitiva.md), [`corpo-entrevista-joao.txt`](./corpo-entrevista-joao.txt)), com extração de entidades, palavras-chave e sintagmas nominais via um pipeline baseado em Makefile ([`Makefile`](./Makefile)), e análise de sentimento das falas ([`sentimento-falas.py`](./sentimento-falas.py))

Inclui também os registos fotográficos relacionados com a realização da entrevista ([`foto-1.pdf`](./foto-1.pdf) a [`foto-11.jpg`](./foto-11.jpg)).

Trabalho individual.

## 🇬🇧
First stage of the AVD project, individual: exploring natural language processing (NLP) and sentiment analysis techniques, applied to two distinct corpora:

- **Sentiment analysis of the "Cinderela" short story** ([`sentimento-cinderela.py`](./sentimento-cinderela.py), [`cinderela.txt`](./cinderela.txt), [`grafico-sentimentos.png`](./grafico-sentimentos.png))
- **Personal interview** (with the author's grandmother, Rosa Reis) — transcription ([`entrevista-definitiva.md`](./entrevista-definitiva.md), [`corpo-entrevista-joao.txt`](./corpo-entrevista-joao.txt)), with entity, keyword, and noun chunk extraction via a Makefile-based pipeline ([`Makefile`](./Makefile)), and sentiment analysis of the dialogue ([`sentimento-falas.py`](./sentimento-falas.py))

Also includes the photographic records related to the interview ([`foto-1.pdf`](./foto-1.pdf) through [`foto-11.jpg`](./foto-11.jpg)).

Individual work.
