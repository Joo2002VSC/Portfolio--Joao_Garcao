# OCR

## 🇵🇹
Exercício de reconhecimento ótico de caracteres (OCR), comparando os resultados do **[Tesseract](https://github.com/tesseract-ocr/tesseract)** com os de uma ferramenta de OCR online, na transcrição de páginas facsimiladas de um texto antigo sobre a Hespanha (Espanha).

- 🖼️ [`hespanha-1.png`](./hespanha-1.png), [`hespanha-2.png`](./hespanha-2.png), [`hespanha-3.png`](./hespanha-3.png) — imagens originais
- 📄 [`tesseract-esp1.txt`](./tesseract-esp1.txt) — resultado do Tesseract
- 📄 [`online-ocr-esp1.txt`](./online-ocr-esp1.txt) — resultado da ferramenta de OCR online

O Tesseract produziu um resultado significativamente mais fiel ao texto original do que a ferramenta online testada.

## 🇬🇧

- 🖼️ [`hespanha-1.png`](./hespanha-1.png), [`hespanha-2.png`](./hespanha-2.png), [`hespanha-3.png`](./hespanha-3.png) — original images
- 📄 [`tesseract-esp1.txt`](./tesseract-esp1.txt) — Tesseract result
- 📄 [`online-ocr-esp1.txt`](./online-ocr-esp1.txt) — online OCR tool result

Tesseract produced a significantly more faithful result than the online tool tested.
